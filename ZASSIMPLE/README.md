# ZASSIMPLE

> ## Got an idea? **Dump it.** 💬

**Current version:** v0.2.5  
**Default landing:** [ZASSIMPLE_EN.md](ZASSIMPLE_EN.md)  
**Bahasa Melayu:** [ZASSIMPLE_MY.md](ZASSIMPLE_MY.md)

Language behavior: ordinary conversation may follow the user, while structured ZASSIMPLE tables/cards/record labels follow the active EN/MY method file. English users who start speaking Malay get one light notice that `ZASSIMPLE_MY.md` is available; switching is never automatic.

> **ZASSIMPLE: lightweight on the surface, but lineage stays strong all the way to execution.**

## Start here

1. Open or attach **ZASSIMPLE_EN.md**.
2. Dump your idea naturally.
3. Let ZASSIMPLE distill, preserve decisions, shape architecture, and guide execution one step at a time.

## Internal artifacts

- `ACTION_PLAN.md` — hidden implementation-planning lineage; feeds Architecture and execution.
- `ARCHITECTURE.md` — draft/confirmed architecture derived from owner-controlled decisions.
- `TASKS.md` — executable task slices derived from the current Action Plan.

These files support the method. Users should not need to manage them manually just to brainstorm.
