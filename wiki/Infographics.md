# Infographics

The original ZASS infographic set is retained as **historical visual reference** for the Wiki/reference layer.

## Important version note

The existing infographic set was authored for **ZASS v0.3.2**.

Current Full ZASS is **v0.3.5**.

Therefore the old graphics are **not authoritative for current command semantics**.

Notable differences since v0.3.2:

- the dedicated Full-ZASS `PARK` command was removed;
- `PARKED` remains a state;
- `PROCEED` now approves exactly the explicitly listed `PROPOSED FOR PROCEED` set;
- Evidence Confidence is separated from Architecture Readiness and has mandatory display rules at defined architecture-assessment points;
- productization now prioritizes validator/automation/field evidence.

When an infographic conflicts with the current method files, the current repository wins.
