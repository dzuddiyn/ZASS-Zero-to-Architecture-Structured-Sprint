# ZASSELECTION

**Current version:** v0.1.0

ZASSELECTION is for difficult choices where the main problem is **selection**, not architecture.

> **Many options, one explainable decision.**

## When to use it

Examples:

- choose a rental home;
- compare job offers;
- choose a computer or phone;
- select software or subscriptions;
- choose between repairing, buying or delaying;
- select which project idea should continue.

It does not replace professional medical, legal or financial advice.

## Relationship to ZASS

| Method | Purpose |
|---|---|
| ZASS | raw idea → decisions → architecture |
| ZASSIMPLE | lightweight conversational idea → architecture |
| ZASSELECTION | dilemma → comparison → owner selection |

If a ZASS project discovers a difficult choice, that choice may be evaluated in ZASSELECTION.

The result returns to ZASS as a **candidate decision**, not an automatic LOCKED decision.

## Core workflow

```text
raw dilemma
→ QUICK or DEEP
→ define the real decision
→ define MUST-HAVE
→ separate needs from preferences
→ list options
→ check evidence / cost / risk / feelings
→ eliminate MUST-HAVE failures
→ shortlist
→ cheapest useful tie-breaker
→ AI recommendation
→ owner SELECT
→ record rationale / consequences / revisit trigger
```

## Quick Selection

Use when the decision is small or easy to reverse.

Typical characteristics:

- up to about three main options;
- few critical criteria;
- low human/financial impact;
- information mostly available.

## Deep Selection

Use when a decision is expensive, hard to reverse, high-impact or evidence-poor.

It may include:

- MUST-HAVE constraints;
- weighted criteria when genuinely useful;
- worst-case review;
- cost;
- reversibility;
- evidence quality;
- unknowns;
- emotional fit;
- human impact;
- revisit triggers.

## Information discipline

Keep these distinct:

```text
EXPLICIT
EVIDENCE
INFERRED
UNKNOWN
```

Feelings are valid decision inputs, but they are not factual evidence.

## Owner authority

AI may compare and recommend.

Only the owner makes the final:

```text
SELECT [option]
```

A minimum decision record includes:

- decision;
- selected option;
- reason;
- consequences;
- confidence;
- revisit trigger;
- selected by;
- selected at.
