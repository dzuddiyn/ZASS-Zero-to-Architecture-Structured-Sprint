# ⚡ The PICKS Trick with ZASSELECTION
## The Fastest Product Review Method

```text
P → I → C → K → S
```

### 🎯 P — Pin the Problem

Define what you actually want to choose, for example:

```text
I need a PC for agentic coding.
```

### 🚧 I — Identify Must-Haves

Define what the product must have, for example:

```text
RAM ≥ 32GB
SSD ≥ 1TB
Suitable GPU
Budget around RM4,000
```

### 📊 C — Compare Options

AI will build and continuously update the **Selection Matrix**.

For example:

| Criteria | Weight | Option A | Option B | Option C |
|---|---:|---:|---:|---:|
| Performance | 30% | 7 | 9 | 8 |
| Upgrade | 20% | 8 | 9 | 7 |
| Price | 30% | 7 | 8 | 8 |
| Practical Fit | 20% | 8 | 9 | 8 |
| **TOTAL** | **100%** | **7.4** | **8.7** | **7.8** |

Quick visual:

```text
Option A   ━━━━━━━━━━━━━━━        74
Option B   ━━━━━━━━━━━━━━━━━      87
Option C   ━━━━━━━━━━━━━━━━       78
```

> **Selection Score Bar** is shown only when the numeric totals have a valid basis. Standard style uses a clean solid `━` line with space padding—no `░` filler blocks or outer box. Provisional scores use `PROVISIONAL / AI-PROPOSED`; otherwise ZASSELECTION keeps the comparison qualitative. The bar summarizes existing evidence and never creates new evidence.

### ⭐ K — Keep the Best Candidate

AI gives its current recommendation, for example:

```text
🤖 AI Recommendation:
Option B

Why:
Best balance of performance, upgradeability and price.
```

👉 **Your selection?**

### 💾 S — Select & Save

**CHOOSE according to YOUR OWN TASTE!**

Then save the selection as:

- updated `.md`;
- GitHub commit; or
- later, through **AI-SYNC**.
