# ZASS Examples

These examples are **teaching fixtures**, not claims of real-world validation. They exist to show how ZASS records evolve from conversation to decisions and architecture.

## 01 — Small Farm Planner

[01-small-farm-planner/](01-small-farm-planner/README.md) demonstrates a complete full-ZASS flow:

    raw idea
    → questions and constraints
    → options
    → proposed decisions
    → owner review
    → PROCEED
    → LOCKED decisions
    → COMMIT
    → DRAFT ARCH
    → BUILD ARCHITECTURE
    → YA, CONFIRM ARCHITECTURE

It includes:

- a project-specific ZASS.md;
- an ACTION_PLAN.md;
- a confirmed ARCHITECTURE.md;
- an end-to-end WALKTHROUGH.md;
- English and Malay example READMEs.

The scenario is intentionally small so the method is easier to inspect than the product itself.
